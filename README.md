# Smart Queue Management System

## Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication

## Roles
- Admin
- Doctor
- Patient

## Features
- Role-based access
- Smart FIFO queue
- Live patient notifications
- Audit logging
- Admin analytics dashboard

## How to Run
1. Create virtual environment
2. Install requirements
3. Run `uvicorn app.main:app --reload`

Visit: http://127.0.0.1:8000/docs
